## 3. 已实现功能与关键技术决策

### M0 原始工程及工程验证修复

- 建立 `apps/web`、`apps/api`、`apps/collab`、`packages/database`、`packages/shared` 的工作区边界，使用 pnpm Workspace 和 Turborepo。
- Web 使用现有 BlockNote、Yjs 和 Hocuspocus provider 实现富文本同步、在线光标与连接状态；未自行实现 CRDT 或编辑器引擎。
- API 提供本地 `/health`；Collab 使用固定开发令牌和合法房间名校验，保存本地二进制快照。
- 提供 Prisma schema 草案、客户端生成入口、单元测试和双窗口协作回归测试；CI 配置使用 frozen-lockfile。

| 决策或修复 | 原因及影响 |
| --- | --- |
| NestJS API 与 Collab 分离 | 业务资源与同步传输职责分开，沿用 ADR-0001；正式认证和 ACL 仍待后续实现 |
| 持久化 Yjs binary | 使用 `Y.encodeStateAsUpdate` 保存、`Y.applyUpdate` 加载，保留 CRDT 身份与合并历史，沿用 ADR-0002；不从 BlockNote JSON 重建历史文档 |
| 快照临时文件写入后 rename | 避免直接覆盖正在读取的快照；保持原有二进制格式，但不承诺断电后的持久性 |
| `doc:<id>` 映射为 `doc-<id>.bin` | Windows 的冒号路径导致原子重命名 `EINVAL`；仅改变本地文件名，WebSocket 房间名和 Yjs 格式不变 |
| 移除 `@mantine/utils@^8.3.0` | 初次安装因该版本不存在而失败；源码未引用，移除无效依赖即可，不升级既有技术栈主版本 |
| 显式安装 `y-prosemirror`、`y-protocols` | BlockNote 将协作相关依赖声明为可选 peer，但本项目实际使用协作入口；缺失时浏览器空白、构建失败 |
| 适配 `awareness ?? undefined` | Hocuspocus 的可空类型与 BlockNote 可选属性不匹配；传递所需 awareness 接口，修复类型检查 |
| API 关闭 TypeScript 增量编译 | Nest 清空输出目录后，目录外增量缓存仍可能跳过生成，导致 `dist/main.js` 缺失；先 typecheck、再连续两次 build 均已实际验证产物存在 |
| 限制间接依赖 `schema-utils` 为 `4.3.3` | Nest CLI 固定的 webpack 与新版 schema-utils peer 要求冲突；严格 peer 安装已通过，升级 CLI 时需复核该约束 |
| 独立端口与临时快照目录的 E2E | 避免使用日常 `.local` 数据；测试读取正文时排除在线光标标签，使用户标识不会被误判为文档内容 |

以上修复均发生在原 M0 工程验证阶段；本次归档没有再次修改实现，也没有新发现需要修复的源码缺陷。

## 6. 实时协作、持久化与安全验证细节

### 协作与恢复路径

现有 E2E 的流程依次为：创建两个独立 BrowserContext → 打开同一文档 → 等待两端“已同步” → A 输入 → B 追加 → B 刷新 → 等待磁盘快照 → 停止 Collab → 双方离线编辑 → 重启并验证收敛 → 等待更新后的快照 → 关闭全部旧上下文 → 再次重启 Collab → 新上下文恢复全文。

正文断言排除了 `.bn-collaboration-cursor__base` 光标标签；因此“访客”名字不被误计为正文，也不作为快照恢复内容。该测试是一条包含多个断言的自动化端到端测试，不宣称每个断言都是独立测试用例。

| 持久化检查 | 状态 | 依据 |
| --- | --- | --- |
| 二进制写入与重新加载，重复应用更新不重复正文 | 通过 | `storage.test.ts` 的实际通过记录 |
| 不存在快照返回空文档 | 通过 | 同上 |
| 非法房间名在文件操作前拒绝 | 通过 | 同上；本轮 WebSocket 探针另验证非法房间认证被拒绝 |
| 损坏快照暴露错误，不静默重置为空文档 | 通过 | `storage.test.ts` 的实际通过记录 |
| 已保存正文在服务与全部客户端重建后恢复 | 通过 | 既有 E2E 的全新服务与浏览器上下文恢复断言 |
| 未完成防抖写入时强杀、断电、磁盘写满 | 未验证 | 没有相应故障注入结果；不能从正常重启测试推导通过 |

快照默认位于 `apps/collab/.local/snapshots/`，文件名为 `doc-<id>.bin`。防抖为 800 ms、最大防抖为 2500 ms；客户端“已同步”不等于服务器磁盘持久化确认。原始 `doc:<id>.bin` 文件没有自动迁移方案，如有旧数据须先备份并单独评估。
