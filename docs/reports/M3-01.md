## 结果与使用流程

原“开发任务 · 规划中”已接入正式 React 页面、NestJS API 和 PostgreSQL。真实账号登录后选择“开发任务”，选择有权访问的工作空间，即可查看三列看板。OWNER / EDITOR 可创建任务、编辑标题和纯文本描述、选择待办 / 进行中 / 已完成；刷新页面后内容及状态恢复，第二个有权账号可读取同一任务。VIEWER 只展示查看能力，直接调用写 API 也返回 403。

用户已明确允许同名任务。本轮以同步提交锁防止同一表单重复提交，以 version 防止过期更新覆盖，不添加标题唯一约束。任务来自真实 API，不复用 Nova 演示数据。

本轮仅完成独立 M3-01 功能切片，不代表整个 M3 完成。未启用指派、截止日期编辑、删除、评论、附件、文档关联、拖拽或实时看板广播。M2 正式协作继续暂停，作者 Undo 缺陷仍未解决。

## API、权限与输入契约

| 路由 | 成功 | 权限 / 行为 |
| --- | --- | --- |
| `GET /workspaces/:workspaceId/tasks` | 200 | OWNER / EDITOR / VIEWER 读取当前空间任务 |
| `GET /workspaces/:workspaceId/tasks/:taskId` | 200 | 校验成员及任务空间归属 |
| `POST /workspaces/:workspaceId/tasks` | 201 | OWNER / EDITOR；title、可选 description；默认 TODO / version=1 |
| `PATCH /workspaces/:workspaceId/tasks/:taskId` | 200 | OWNER / EDITOR；必填 version，至少修改 title / description / status 一项；成功 version+1 |

沿用原 SessionGuard、HttpOnly Cookie、精确 Origin、`X-Weavefield-Request: 1`、JSON 格式及 4 KiB 请求体限制。未登录、过期、撤销或退出为 401；有效成员写入权限不足为 403；非成员、不存在或跨空间任务按既有隐匿策略返回 404；过期 version 返回 409。PATCH 先校验成员及任务归属，再检查可写角色，不泄漏跨空间记录。

DTO 仅含 `id / workspaceId / title / description / status / version`。不接受客户端提交 role、userId、workspaceId、assigneeId、dueAt 或 id；拒绝其他未知字段。

标题 trim 后为 1–200 个 Unicode 字符，原始输入不能含控制字符。描述为 nullable 普通文本，最多 1000 个 Unicode 字符，允许换行和 Tab；规范化换行并移除首尾空白，空白串保存为 null。状态仅接受 TODO / IN_PROGRESS / DONE。PATCH version 为 1–2147483646 的整数，避免数据库 Int 自增溢出。浏览器原生 maxLength 按 UTF-16 单元计数，含补充平面字符时可能比 API 更早达到输入上限。

Swagger 增加 Task 4 个操作，当前总数 22；仅沿用开发环境显式启用的文档入口。没有增加可绕过实际 Guard 的文档执行入口。

## 关键执行流程与取舍

1. **数据库写入。** `TasksService.write()` 与现有成员管理锁定同一 Workspace 父行，在 ReadCommitted 事务中等待后重新读取 Membership。OWNER / EDITOR 才能写入。PATCH 使用 `id + workspaceId + version` 条件更新并自增；条件不匹配抛出 409，事务不写旧数据。读操作在 RepeatableRead 中验证成员并限定空间。复用现有 Task 和 Prisma Client，没有修改 Schema 或新增 Migration。
2. **前端时序。** `TaskManager` 按 userId 创建独立实例；alive / revision 拒绝账号、空间及页面生命周期变化后的迟到响应。工作空间选择与 WorkspacePanel 使用同一个按用户隔离的 key，只保存 ID，不缓存角色或私有正文。
3. **写入全过程保护。** 同步 `writing.current` 先于 React pending 状态置位，持续覆盖 POST / PATCH 及后续空间、角色、任务读取完成或失败。手动刷新、空间选择和页面内管理入口同时以 ref 防护、state 禁用；focus / visibilitychange / 定时任务刷新在写入或编辑草稿期间不替换请求代际。AuthContext 的独立 Session 检查不受阻断。
4. **真实反馈。** 409 保留未提交草稿，先明确告知“加载最新版本”将替换草稿，再读取最新任务。提交结果不明时不重复 POST、不宣称成功；收到真实写入成功后若后续 GET 失败，则明确区分“已保存但刷新失败”。后续读取出现 403 / 404 时清理不可访问内容。成功提示不会被自动刷新吞掉。
5. **UI 复用。** 沿用 A 方案、Tailwind v4 Tokens、既有 Radix Dialog / WorkspacePrimitives、Button、Input、NativeSelect 和 Lucide。Textarea 由 shadcn 官方 Radix registry CLI 生成，使用仓库现有 cn helper。CLI 引入的多余 `cn` 依赖已移除；应用依赖及 lockfile 与基线一致。卡片 hover 160ms，Reduced Motion 禁用卡片过渡；导航共享选中和 Dialog 使用已有外壳行为，不动画化编辑器内容。

## 风险、限制与未验证事项

- **安全。** 沿用 M1 请求时 Session 校验和成员权限事务，不更改 RBAC、认证基础设施或严格协作撤权目标。REST 权限测试不能证明 M2 的 WebSocket 严格撤权；M2 仍暂停。非成员 404、VIEWER 403、未知字段拒绝均经真实 API 验证。
- **一致性。** version 防止静默覆盖，但没有 POST 幂等键。创建结果不明时用户须刷新核对，不能凭同名标题推断某次请求结果。显式离开页面或关闭浏览器可能留下已在服务端提交的请求；迟到响应不会写入新页面，不会自动重试。409 的“加载最新版本”会替换草稿，页面已提前说明。
- **性能。** Task 列表本轮不分页；大量任务仍需后续独立设计。父行锁使同空间任务写入与成员变更串行。构建主 JS 为 589.55 kB（gzip 188.90 kB），保留 >500 kB 警告，未通过提高阈值掩盖。Turbo 远端缓存曾返回 403，运行已自动关闭远端缓存并真实执行。
- **兼容性。** 本地 Chromium 浏览器回归通过。Safari、Firefox、真机中文输入法及完整屏幕阅读器未全部验证，不能声明跨浏览器或辅助技术全面通过。浏览器原生字段长度与 API Unicode 计数的差异如前述。
- **持久化。** Task 普通 PostgreSQL 行写入、迁移升级和重新读取通过；没有实现 Yjs Binary 持久化或服务重启后的协作恢复。Schema / Migration 字节未改变。
- **范围。** 作者 Undo 已知缺陷继续保留，未宣称修复。没有任务删除、指派、截止日期、Flow、EntityLink、AI、实时通知、生产部署或后续 M3-02。
- **外部 CI。** 本轮未提交或推送，未产生新 GitHub Actions 结果；基线历史 CI 不代替本轮本地验收。
