## 状态、安全与生命周期

- **选择器。** 长名称视觉截断，DOM 全文与 title 保留；菜单限制在 viewport 内，支持鼠标、键盘、触摸。字段标题与按钮独立，避免把带 Portal 的 Select 嵌在原生 label 中引起关闭/重开焦点问题。Radix 内置隐藏表单字段保留 name/value；成员添加/改角色通过真实 FormData 与 API 验证，form.reset 后恢复默认 VIEWER。原 NativeSelect 文件保留，但正式页面已无使用位置。
- **真实反馈。** 只在用户操作及其必要读取成功后发成功 Toast，避免读取超过 4 秒时提示在弹窗关闭前过期。已提交但读取失败、提交结果不明、401/403/404/409 仍保留页面内恢复说明；不自动重复 POST，不用 Toast 掩盖失败。
- **刷新。** loading 与 refreshing 分离。后台读取的一般网络/503 错误保留上次成功读取的数据并展示错误；401、403、404 清理不可继续显示的状态。未将私有列表、角色或文档持久缓存到 localStorage；空间选择仍只保存原有按 userId 隔离的 ID。
- **请求并发。** alive/revision 与同步写入 ref 保留，保护覆盖写请求及后续读取。文档写入开始时同步使尚未完成的父级 GET 失效；旧响应不能推进子控制器刷新。重复刷新、快速切换、退出及迟到响应均有真实浏览器回归。
- **错误恢复。** 父级刷新区分手动与自动来源。自动刷新不清掉创建/归档草稿和已提交后的恢复状态；用户主动刷新允许重新读取并恢复列表。失效归档意图会清理，不能在选中另一文档时重新弹出旧确认框。文档列表和详情复用相同、已鉴权的元数据 DTO，刷新可完成被替代的详情读取，避免 reading 状态滞留；重命名表单保持同一 id 的 DOM，保留未提交输入。
- **路由。** 侧栏与顶栏不随正文重挂载。浏览器 Back/Forward、焦点转移与主阅读区滚动归零已验证；快速路由变化使旧动画回调失效。旧正文退出时 inert，避免点击过渡中的旧页面。Nova 始终在 Motion 容器之外，离开/返回 Nova 不给富文本正文、Selection 或协作光标施加动画。
- **减少动效。** 安装的 Motion 14.7.1 hook 仅捕获初值，因此新增 useSyncExternalStore 媒体查询订阅，实时响应系统偏好变化；业务页切换立即完成。Select、Skeleton、进度图标和 Toast 有独立 Reduced Motion 样式，不作用于编辑器。

服务端 Task、Auth、Session、RBAC、Prisma Schema/Migration、Hocuspocus、Yjs 及 CollaborativeEditor 字节未改动。REST 回归不代表 M2 严格撤权已成立；M2 继续暂停。作者 Undo 缺陷仍未修复。
